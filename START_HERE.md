# 🚀 START HERE - First Time User Guide

**Welcome!** If you're new to this toolkit, follow these simple steps.

## ⚡ Quick Start (5 Steps)

### Step 1: Open Terminal/Command Prompt

**Windows:**
- Press `Windows + R`
- Type `cmd` and press Enter

**Mac:**
- Press `Cmd + Space`
- Type "Terminal" and press Enter

**Linux:**
- Press `Ctrl + Alt + T`

### Step 2: Navigate to This Project

```bash
cd path/to/LLMInterpretability
```

Not sure where it is? If you downloaded a ZIP:
- **Windows**: Probably in `C:\Users\YourName\Downloads\LLMInterpretability`
- **Mac**: Probably in `/Users/YourName/Downloads/LLMInterpretability`
- **Linux**: Probably in `/home/yourname/Downloads/LLMInterpretability`

### Step 3: Run Automated Setup

```bash
python setup_interactive.py
```

**Note:** If `python` doesn't work, try:
- Windows: `py setup_interactive.py`
- Mac/Linux: `python3 setup_interactive.py`

This will:
- ✅ Check your system
- ✅ Install all required software
- ✅ Download a test model
- ✅ Verify everything works

**⏱️ This takes 10-20 minutes.** Go grab a coffee! ☕

### Step 4: Choose How You Want to Use It

After setup completes, pick **ONE** of these options:

#### Option A: Interactive Menu (Easiest!) 🌟
```bash
python run_interactive.py
```
- Simple menu with numbered choices
- No coding required
- Just press numbers and follow prompts!

#### Option B: Web Interface (Pretty!) 🎨
```bash
streamlit run app.py
```
- Opens in your web browser
- Buttons and forms
- Visual and intuitive!

#### Option C: Jupyter Notebooks (Learning!) 📚
```bash
jupyter notebook
```
- Interactive tutorials
- Lots of explanation
- Great for understanding how it works!

### Step 5: Start Exploring!

Follow the on-screen instructions in whichever interface you chose!

## 🆘 Something Went Wrong?

### "python: command not found"
Install Python from https://www.python.org/downloads/
Make sure to **check "Add Python to PATH"** during installation!

### "Permission denied"
- **Windows**: Right-click Command Prompt → "Run as administrator"
- **Mac/Linux**: Add `sudo` before the command: `sudo python setup_interactive.py`

### Still stuck?
Run the diagnostic tool:
```bash
python check_installation.py
```

It will tell you exactly what's wrong and how to fix it!

Or check **TROUBLESHOOTING.md** for detailed help.
